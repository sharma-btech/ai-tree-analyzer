\# 🌳 AI Tree Analyzer



AI-powered web application that analyzes tree images and provides simple tree insights.



\## ✨ Features



\- 🌳 Tree image upload

\- 🤖 AI-powered image analysis

\- 💚 Tree health estimation

\- 🍃 Leaf condition analysis

\- ⚠️ Possible issue detection

\- 💧 Water requirement suggestion

\- 💡 Tree care suggestion

\- 📱 Responsive web interface
